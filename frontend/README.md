# Frontend scaffold

Static HTML, CSS, and JavaScript.

```bash
cd frontend
python3 -m http.server 5173 --bind 127.0.0.1
```

Open http://127.0.0.1:5173. The page loads only local `data/demo_cases.json`. It does not connect to FastAPI. All preview account groups use selected authentic synthetic rows and are **not** fraud detections.
